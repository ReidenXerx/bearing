bearing · ast-grep

A broken pattern looks exactly like a clean codebase.

ast-grep searches the syntax tree. Give it a pattern that does not parse and it searches nothing — then answers like a search that found nothing.
the pattern parses
fetch($URL, $$$OPTS)
the pattern does not parse
fetch($URL, { method: $M
$ ast-grep run -p 'fetch($URL, { method: $M' order.ts  → [] · exit 1 · stderr empty
$ ast-grep run -p 'fetch($URL, $$$OPTS)' no-fetch.ts     → [] · exit 1 · stderr empty  ← identical. the skill proves a pattern on a known site first.
