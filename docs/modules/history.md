# 📜 Git history

**Finds why code is the way it is before anyone changes it.** The commit and the PR behind a magic number or an odd guard, so a deliberate fix is not removed as noise. The skill carries where git points at the wrong commit: plain blame names the formatter, `-C` follows a moved block only past 40 characters, `log -L` finds no TypeScript method, a shallow clone blames everything to one commit. Opt-in; uses git and `gh`.

The whole of it — every trap, and what to do about each — is the skill the agent loads: [`bundle/skills/bearing-history/SKILL.md`](../../bundle/skills/bearing-history/SKILL.md).
