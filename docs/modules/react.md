# ⚛️ React

**Catches the form bugs that fail silently.** A field owns its `Controller`; spreading `field` keeps the `ref` that focus-on-error needs; a `name` typed `FieldPath<T>` turns a renamed field into a compile error instead of a value missing from the payload.

The whole of it — every trap, and what to do about each — is the skill the agent loads: [`bundle/skills/bearing-react/SKILL.md`](../../bundle/skills/bearing-react/SKILL.md).
