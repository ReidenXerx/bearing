# 🖼 Publish

**Visuals that publish what you built — and make one true claim.** A feature card, a README hero, a social preview, a release header: each states ONE thing, traceable to code or a measurement, shows *this* feature rather than the platform's default, and survives the size it is read at. Each is an infographic drawn from a real run, every mark one item from its data (a funnel, swimlanes, a with/without diptych, a timeline), never a slide of sentences in boxes. Cards are HTML; a bundled renderer waits for the card to say it is finished and fails on a broken image — then the agent looks at the result. From a publisher's method on real mod and product pages. Opt-in; needs Playwright.

The whole of it — every trap, and what to do about each — is the skill the agent loads: [`bundle/skills/bearing-publish-visuals/SKILL.md`](../../bundle/skills/bearing-publish-visuals/SKILL.md).
